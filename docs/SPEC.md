# CSPSO 研究规格

规格版本：0.1  
最后核对：2026-09-17  
状态：当前实现规格，尚未冻结为最终正式实验协议。

## 1. 研究对象与结论边界

研究问题是：粒子在某一代采用某个邻域记忆后，这次信息采用对未来整个种群的搜索收益产生了多少影响，以及稀疏干预监督能否改善该长期价值差的估计和最终搜索表现。

当前首先归因于“一名粒子在一代中采用某个候选领袖记忆”的事件。它不等同于某个粒子的永久贡献，也不构成对总收益的唯一可加分解。

共享参数 MAPPO、COMA 形式的反事实优势、历史信用分配和反事实轨迹均有先行研究。本项目候选增量限定为：利用可复制的 PSO 状态、记忆传播和配对随机数，在有限额外函数评估下生成动作价值差监督。是否有效必须由归因诊断、消融和预算公平实验支持。

## 2. 已采纳的 PSO 定义

### S01：优化任务

- 有界、无噪声、连续、单目标最小化。
- 当前目标函数：Sphere、Rastrigin、Rosenbrock、Ackley。
- 默认粒子数 20、维度 10、每轮 100 代。
- 默认边界处理为位置裁剪 `clip`；该选择属于当前实现，不由收缩系数理论自动推出。

### S02：环形邻域和动作

粒子按环排列，每个粒子选择左邻居、自己或右邻居的 `pbest`，离散动作为 `{0, 1, 2}`。所有粒子共享同一个 Actor，一次环境步对应一代同步 PSO 更新。

当前更新为：

```text
v_i(t+1) = chi * [v_i(t)
                  + c1*r1*(pbest_i-x_i)
                  + c2*r2*(pbest_leader-x_i)]
x_i(t+1) = x_i(t) + v_i(t+1)
```

默认 `chi=0.72984`、`c1=c2=2.05`。两个加速系数位于收缩系数括号内，不与惯性权重写法混用。

### S03：局部观测和集中状态

Actor 的单粒子观测为 17 维：

- 自身 4 项：停滞比例、速度范数、与自身 `pbest` 的距离、最近改进；
- 三个候选各 4 项：相对适应度、`pbest` 距离、记忆年龄、累计被采用比例；
- 公共 1 项：剩余代数比例。

Actor 不直接读取全群拼接状态。普通 Critic 和反事实 Critic 在集中训练阶段读取全群拼接观测。

### S04：奖励和回报

设一轮初始化后的全群最好目标值为 `b_0`，第 `t` 代前后的最好值为 `b_t` 和 `b_(t+1)`，固定尺度为：

```text
s = max(abs(b_0), pso_scale_floor)
r_t = (b_t - b_(t+1)) / s
```

所有粒子接收相同团队奖励。训练入口强制 `gamma=1` 且关闭 GAE，因此固定终止预算下的累计回报对应归一化的最终改进。干预标签不直接加入环境奖励。

## 3. 学习结构

### S05：MAPPO 基线

- 共享 Actor：两层网络的基础隐藏宽度为 64，输出三个动作概率；当前通用网络实现还包含项目原有的初始化和归一化设置。
- 集中 Critic：隐藏宽度由 `critic_hidden_size=128` 覆盖。
- 学习率：Actor 与普通 Critic 均为 `3e-4`。
- PPO clip：`0.2`。
- 非循环策略、共享参数、集中价值函数。

### S06：反事实 Critic

反事实 Critic 估计 `Q_i(S, a_-i, k)`，输入为集中状态、替换后的联合动作、粒子编号和候选动作。普通监督使实际动作预测接近累计回报；干预监督约束两个动作预测差。

Actor 使用策略加权反事实基线：

```text
A_i = Q_i(S, a_-i, a_i) - sum_k pi_old(k|o_i) Q_i(S, a_-i, k)
```

该形式借鉴 COMA，不作为本项目的新颖性主张。

### S07：四种训练模式

| 模式 | Actor 优势 | 反事实 Critic | 干预差监督 |
|---|---|---|---|
| `mappo` | 普通 MAPPO 优势 | 无 | 无 |
| `cf_no_intervention` | 反事实优势 | 普通累计回报监督 | 无 |
| `cf_intervention` | 反事实优势 | 普通监督 | 真实稀疏干预差 |
| `cf_intervention_shuffled` | 反事实优势 | 普通监督 | 历史池错配标签 |

标签打乱只用于证伪。标签来源发生错配不等于对照已经科学公平，跨批次分布差异仍需单独检查。

## 4. 干预协议

### S08：单次干预

默认每 4 个训练回合触发一次干预事件，在该回合均匀随机选择一个代数和一个粒子，并从另外两个领袖动作中随机选择替代动作。当前实现要求 `n_rollout_threads=1`。

保存内容包括 PSO 完整快照、环境随机数状态、集中观测、联合动作和 Torch 随机数状态。替代分支只改变当前粒子当前代的领袖动作；当前代其他粒子动作保持不变。

### S09：后续延续

真实分支直接复用主轨迹。替代分支从快照恢复，使用同一冻结策略和配对随机数延续到同一代数终点。未来动作不固定为相同序列，而是由同一策略分别响应两条分支的状态。

循环策略在当前实现中关闭，因此替代分支每步使用零 RNN 状态不改变策略语义。若以后启用循环策略，必须重新定义并验证隐藏状态恢复。

### S10：干预标签

对最小化问题，当前标签为：

```text
delta = (b_T_alt - b_T_real) / s
```

正值表示真实选择优于替代选择。干预损失约束：

```text
Q_real - Q_alt = delta
```

一次延续只是一个随机样本。训练可稀疏采样；归因准确性验证必须在独立诊断状态上使用多个未来随机种子估计均值和不确定性。

## 5. 预算口径

### S11：函数评估分类

- `main`：初始化和主 PSO 轨迹的真实目标函数调用；
- `intervention`：替代分支的真实目标函数调用；
- `eval`：独立评估回合的真实目标函数调用；
- `train = main + intervention`；
- `total = train + eval`。

默认 20 粒子、100 代时，每个完整主回合为 `20 + 20*100 = 2020` 次函数评估。预算公平比较优先使用累计函数评估字段，而不是 TensorBoard 的环境步数。

## 6. 当前未冻结事项

以下内容在正式大规模实验前必须解决或明确登记：

1. 独立归因诊断集的状态采样、重复次数和不确定性统计。
2. 训练、验证和测试目标函数实例的划分；当前仅有四个固定解析函数，没有实例生成协议。
3. 正式训练步数、评估间隔、评估回合数和模型选择规则。
4. 标签历史池错配是否构成公平的随机标签对照。
5. 同总函数评估预算基线的精确换算方式。
6. 多种子统计检验及多重比较处理。
7. 完整运行清单 `manifest` 的自动记录；当前逐回合 JSONL 尚不能替代完整配置记录。

上述事项未冻结前，可以进行 A1 正确性验证和小规模消融，不把结果表述为正式研究结论。
