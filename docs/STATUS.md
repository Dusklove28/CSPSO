## 已实现

- 环形邻域收缩系数 PSO，Actor 为每个粒子选择左、自己或右侧领袖。
- 共享参数 MAPPO、集中 Critic 和条件动作反事实 Critic。
- `mappo`、`cf_no_intervention`、`cf_intervention`、`cf_intervention_shuffled` 四种模式。
- 完整 PSO 快照、替代分支延续、配对环境与 Torch 随机状态。
- 主轨迹、干预、独立评估和总函数评估累计日志。
- 每回合 `episode_metrics.jsonl` 和 CSV 汇总入口。
- 标签历史池，使单样本稀疏干预也能执行跨批次错配对照。
- TensorBoard 使用单一 Run 下的普通 scalar 标签；旧实现把每个指标拆成独立 Run，已在当前工作单元修正。
- 训练入口支持 `--results_dir`，可将运行写入按日期组织的 `runs/<date>/PSO/...`。
- 每个训练 Run 自动生成 `run_manifest.json`，记录完整参数、命令、Git 状态、运行环境和完成/失败状态。
- 最后一个训练回合会强制执行评估，最终 checkpoint 有对应的独立评估指标。
- `scripts/run_formal_pso.ps1` 固化四函数、四模式、五种子的主批次，并支持按完成 manifest 断点续跑。
